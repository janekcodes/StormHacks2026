# C2 · Hopper's A-0 compiler

## Hook

Grace Hopper's first step from machine code to words.

## Caption

Grace Hopper's A-0 system, finished in 1952, translated symbolic instructions into machine code for the UNIVAC I. It was an early compiler, a first step toward programming in something closer to English.

## Caveat

The label 'first' applies to the A-0 system as an early compiler, not to a compiler in today's full sense.

## Stats

- **System:** A-0, 1952 (wiki-hopper)
- **Machine:** UNIVAC I (wiki-hopper)
- **Idea:** reusable subroutines (wiki-hopper)
