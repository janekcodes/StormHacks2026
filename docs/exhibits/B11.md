# B11 · Tensor Processing Unit

## Narration draft

AI accelerators are built around matrix multiply. A systolic array pulses data through a grid of multiply and accumulate cells, so every value is reused without another trip to memory. The first TPU went into service in 2015, and its matrix unit was two hundred fifty-six by two hundred fifty-six.

## Notes

- Matrix size `256 x 256` written out for speech.
- "multiply-accumulate" written as "multiply and accumulate" for the ear.
