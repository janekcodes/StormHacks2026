# C5 · Software engineering & Apollo code

## Hook

A conference coined the field, and Apollo flew its code to the Moon.

## Caption

The term software engineering was coined at a 1968 NATO conference as projects grew too big to hand-craft. The next year Margaret Hamilton's team flew the Apollo 11 guidance software to the Moon.

## Stats

- **Term coined:** NATO conference, 1968 (Wikipedia: Software engineering)
- **Apollo 11:** 1969 (Wikipedia: Margaret Hamilton (software engineer))
- **Led by:** Margaret Hamilton (Wikipedia: Margaret Hamilton (software engineer))
