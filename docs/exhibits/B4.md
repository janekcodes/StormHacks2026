# B4 · Manchester Baby: first stored program

## Hook

The first machine to run a program stored in its own memory.

## Caption

On June 21, 1948, the Manchester Baby ran the first program stored in electronic memory. The program lived in the same store as the data, the pattern every computer since has followed.

## Stats

- **First program ran:** June 21, 1948 (wiki-baby)
- **Store:** 32 words of 32 bits (wiki-baby)
- **Purpose:** test the Williams tube memory (wiki-baby)
