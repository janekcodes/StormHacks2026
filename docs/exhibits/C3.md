# C3 · FORTRAN & LISP

## Narration draft

FORTRAN let engineers write formulas instead of machine code. IBM shipped its compiler in 1957. One line of code was one card, eighty columns wide, and a program was a deck of cards. Its sibling LISP arrived at MIT in 1958. Pick a statement in this portal and punch it.
