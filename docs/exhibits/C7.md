# C7 · Relational databases

## Hook

Data as tables, and a language to ask them questions.

## Caption

Edgar Codd's 1970 paper described data as relations, or tables, that could be queried in a uniform way. The relational model became the basis of SQL and nearly every database in use today.

## Stats

- **Paper:** A Relational Model of Data, 1970 (wiki-relational)
- **Author:** Edgar F. Codd (wiki-relational)
- **Descendant:** SQL databases (wiki-relational)
