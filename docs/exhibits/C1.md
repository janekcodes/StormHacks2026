# C1 · Patch-cable programming

## Narration draft

ENIAC's first programmers, including Kay McNulty, Betty Jennings and Frances Bilas, set up each problem by rewiring cables and switches. Changing the program meant changing the machine itself. The program was the wiring. The idea of a stored program, one that lives in memory instead of in cables, came with EDVAC in 1945.
