# C10 · Bundle Tower: React & Next.js

## Narration draft

React, Next.js and the modern web stack made software composable, and made pages heavier. In this portal, each square stands for one kilobyte. The median mobile page of 2025 is about two point five six megabytes, with seventy-five requests and over six hundred kilobytes of JavaScript.

## Notes

- Web-weight numbers come from the exhibit stats (HTTP Archive Web Almanac 2025).
- Decimals written out for speech.
