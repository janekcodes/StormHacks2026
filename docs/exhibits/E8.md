# E8 · Screen readers go mainstream

## Hook

A computer that reads its own screen aloud, now built into the phone.

## Caption

By 2009 screen readers had moved from specialist software into mainstream devices, led by VoiceOver on the iPhone 3GS. They read interfaces aloud so blind and low-vision people can use them.

## Stats

- **VoiceOver on iPhone:** 3GS, 2009 (Wikipedia: Screen reader)
- **Examples:** JAWS, NVDA, VoiceOver (Wikipedia: Screen reader)
- **Purpose:** access for blind and low-vision users (Wikipedia: Screen reader)
