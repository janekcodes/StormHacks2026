# P5 · Ada Lovelace's Note G

## Hook

The first published algorithm, written for a machine that was never built.

## Caption

Ada Lovelace's 1843 notes on the Analytical Engine include Note G, which steps through a method for computing Bernoulli numbers. It is widely read as the first published algorithm written for a computing machine.

## Caveat

The label 'first' applies to the published algorithm in Note G, not to a working machine.
