# S3 · The Bloat Audit

## Hook

How heavy is the web? This museum measures its own weight.

## Caption

The Bloat Audit turns the museum performance budget into an exhibit. It tracks the median web page, which grew to about 2.56 megabytes in 2025, and asks how much of that weight actually serves the visitor.

## Stats

- **Median page:** 2.56 MB (almanac)
- **Median requests:** 75 (almanac)
- **Median JavaScript:** 632 KB (almanac)
