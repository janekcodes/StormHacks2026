# D8 · Mosaic browser

## Hook

The browser that put pictures on pages and the web on the map.

## Caption

NCSA Mosaic, released in 1993, put images and text on the same web page and became the first browser used by the millions. It is widely credited with igniting the web boom.

## Stats

- **Released:** 1993 (Wikipedia: Mosaic (web browser))
- **Made by:** NCSA (Wikipedia: Mosaic (web browser))
- **Impact:** ignited the web boom (Wikipedia: Mosaic (web browser))

## Sources

- Wikipedia: Mosaic (web browser): https://en.wikipedia.org/wiki/Mosaic_(web_browser)


## Caveat

The 'first browser used by the millions' claim reflects popularity, not the first graphical browser; earlier graphical browsers existed.

## Narration draft
