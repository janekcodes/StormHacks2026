# E6 · IBM PC & Macintosh

## Hook

The business machine, then the machine everyone could point and click.

## Caption

The IBM PC, released in 1981, set the standard for personal computers in business. In 1984 the Macintosh brought the mouse and a graphical interface to a mass audience.

## Caveat

The label 'first' applies to the Macintosh as a successful mass-market computer with a graphical interface, not the first machine to have one.

## Stats

- **IBM PC:** 1981 (wiki-ibmpc)
- **Macintosh:** 1984 (wiki-mac)
- **Macintosh interface:** mouse and windows (wiki-mac)
