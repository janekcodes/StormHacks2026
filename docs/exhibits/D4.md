# D4 · TCP/IP

## Hook

The common language that let different networks speak.

## Caption

Vint Cerf and Bob Kahn described TCP in 1974 as a way to connect separate networks into an internet. On January 1, 1983, ARPANET switched to TCP/IP, the event many mark as the internet's birthday.
