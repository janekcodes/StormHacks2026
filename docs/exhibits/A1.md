# A1 · Turing's universal machine

## Narration draft

In 1936, Alan Turing described a machine with a tape, a read and write head, and a small table of rules. He showed that it could carry out any computation that a person could follow step by step. This exhibit adds one to a binary number. Step it, and watch the carry ripple to the left.
