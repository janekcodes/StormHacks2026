# B2 · ENIAC

## Narration draft

ENIAC was the first general-purpose electronic digital computer. It was finished in 1945 and unveiled in February 1946. Inside sat about seventeen thousand five hundred vacuum tubes, and the machine weighed about twenty-seven tons. It could run five thousand additions every second. In this portal, every glowing dot stands for fifty tubes. Some have just burned out. Find them and swap them.
