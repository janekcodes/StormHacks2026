# B3 · The transistor

## Narration draft

Bell Labs built the first transistor in 1947, from germanium. In 1954, Morris Tanenbaum made the first silicon one there. The work won the Nobel Prize in 1956. A transistor is a switch with no filament to burn out. Flip the base in this portal and watch the current flow.
