## Steps

1. **Research** in `docs/exhibits/<ID>.md`: at least 2 independent sources for every date and number; note any contested "first"; write the caveat if needed.
2. **Portal spec** (same file): the one interaction, in one sentence ("Drive the mouse and chord keyset to edit a shared document"), inputs, states, what the visitor learns, accessibility notes. If it can't be stated in one sentence, it is not ready.
3. **Content:** caption (2 to 3 sentences ending in the interaction prompt), hook, 3 sourced stats, narration written for the ear.
4. **Portal package** following 08's structure: logic first with tests, then UI.
5. **Object:** model to `docs/assets/model-spec.md`, through `pnpm assets:build`.
6. **Flip the tier** in `exhibits.json` and BLUEPRINT in the same PR (the 02 consistency check enforces it), with a changelog row.
7. **Guide evals:** add at least 2 golden questions about `<ID>`.
